## Add a project

1. Put a square icon in `icons/` (256×256 PNG is plenty). Skip this and the page draws a lettered tile instead.
2. Open `projects.js` and copy the NotchMic block to the top of the list. Change `name`, `blurb`, `year`, `icon`, `site`, `source` and `tags`. Leave out any you don't have.
3. Commit and push. GitHub Pages updates the site within a minute.

Projects show in the order they appear in `projects.js`, so put the newest first.

To preview before pushing, run `python3 -m http.server` in this folder and open http://localhost:8000.
